# 🏋️ FitLog - Workout Library & Planner

FitLog is a modern, fast, and responsive web application designed to help fitness enthusiasts browse workouts, track their daily routines, and manage their personalized fitness logs. Built with **Next.js 14 (App Router)** and styled using **Tailwind CSS**, this app provides a seamless user experience for managing your daily hustle.

---
## 🚀 Live Demo
You can view the live deployment of this project here: bespoke-maamoul-3f3686.netlify.app

---

## ✨ Features

- **⚡ Workout Library:** Browse a comprehensive collection of workout exercises with detailed badges for equipment, muscle groups, and ratings.
- **📅 Today's Plan Manager:** Add up to five lifts to your daily routine, track your progress, and manage what needs to be done.
- **💾 Saved Workouts:** Bookmark your favorite workouts to access them later without losing your preferences.
- **📊 Real-time Metrics Dashboard:** Dynamically calculates and displays total exercises, total minutes, and total estimated calories burned for the day's plan.
- **🔔 Interactive Toasts & Feedback:** Seamless instant notifications using `react-hot-toast` whenever you add, remove, or complete a workout.
- **📱 Fully Responsive Design:** Clean, dark-themed UI optimized heavily for both mobile screens and desktop monitors.

---
## 🛠️ Technologies Used

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS & FontAwesome Icons
- **State Management:** React Context API (`WorkoutContext`)
- **Notifications:** React Hot Toast
- **Deployment:** Netlify (Static Export)
