# 🏋️ FitLog - Workout Library & Planner

FitLog is a modern, fast, and responsive web application designed to help fitness enthusiasts browse workouts, track their daily routines, and manage their personalized fitness logs. Built with **Next.js 14 (App Router)** and styled using **Tailwind CSS**, this app provides a seamless user experience for managing your daily hustle.
